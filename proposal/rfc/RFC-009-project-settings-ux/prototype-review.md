# RFC-009｜交互附件核对

> 2026-09-20；设计稿采用模拟数据，未调用真实项目 API。以下均是设计附件核对，不计入生产 PS 验收。

## 1. 打开方式

在仓库根运行：

```sh
bun run proposal/rfc/RFC-009-project-settings-ux/prototype/preview.ts --serve
```

本地地址：[项目设置交互稿](http://127.0.0.1:5199/)。只有本机环回端口；入口不连真实 API。
默认预览不显示演示控制；只有[专用评审模式](http://127.0.0.1:5199/?review=1)可切换角色和模拟失败。此工具不进入正式产品。
构建产物在 `/private/tmp/crewstation-project-settings-rfc009/`，源文件在本 RFC 的 `prototype/`。
重新运行不带 `--serve` 的命令可重建已运行的预览，浏览器随后刷新。
若端口被占用，先确认占用者，不要结束其他任务的服务。

## 2. 复用和范围

使用生产的 Button、Card、FormField、Tabs、Stack、ActionRow、Badge、DefinitionList、ConfirmationPanel、ActionNote、GlyphIcon 和主题 CSS。
新 CSS 只承担附件布局；没有引入组件库、安装依赖或改生产源码。

可操作：

- 设置／资源入口与各组切换；开发者、负责人、管理员三个模拟视角。
- 变量新增／修改／密钥空值、模拟保存失败与重试、具名删除／取消确认、环境草稿和离开确认。
- 展示资料与可见范围的分别编辑、保存／取消；示例成员查找与角色保存。
- API 文档展开、模拟试调与申请；事件／数据入口的去向说明；复制示例变量名。
- 归档的模拟确认；技术详情、版本记录等按需展开。

只示意位置、尚未接通真实行为：Swagger、真实账号目录／高级 ID／转移负责人／移除成员、实际可见性检查、完整能力说明、代码与数据页跳转、异步保存竞态、真实归档及后端错误。
预览身份切换会重置该视图的模拟数据，刷新会清空全部模拟修改。附件不演示浏览器地址与 beforeunload 保护。
这些能力在实施规格和 PS 验收中保留，不能以附件的简化演示替代生产实现。

## 3. 本轮真实浏览器核对

通过 Codex 内置浏览器操作附件，未改变真实登录身份或业务配置。

| 检查 | 结果 |
|---|---|
| 默认设置页 | 直接进入开发变量；表单与历史初始收起 |
| 开发者生产组 | 显示只读和维护人，无新增／修改／保存入口 |
| 负责人生产组 | 出现编辑入口，保留共用生产组与后续发布生效说明 |
| 空变量名保存 | 字段级错误出现，焦点回变量名 |
| 切开发→生产→开发 | `DEMO_GREETING` 与输入 `草稿保留验收` 保留 |
| 模拟保存 HTTP 503 | 原名和值留存，无成功回执 |
| 有草稿时切资源 | 显示离开确认；“继续编辑”留在原页 |
| 改为成功后重试 | 列表出现新变量，显示第 8 版与新容器注入说明；焦点回“新增变量” |
| 更新密钥 | password 字段初始为空（长度 0），不回填占位符 |
| 两个应用表单 | 修改用途和可见范围后只保存用途；范围仍以未保存的“全部登录用户”保留，随后可独立保存 |
| 成员 | 点击添加才展开，查找 `dev@example.test` 后保存“测试者”；列表显示新角色 |
| API 路径 | 独立资源入口→查看文档→模拟试调，结果明确标模拟及非真实 API |
| 事件路径 | “打开订阅声明”显示代码文件和无会话时的前置条件；没有伪造订阅编辑动作 |
| 1280×720 | 人工检视默认页面；主列表、四个分组与新增入口清楚可见 |
| 390×844 | 四组设置＋五个资源主题均为 `innerWidth=scrollWidth=390`；变量表单展开后宽 332px，无整页横向溢出 |
| 320×720 | 同九个视图均为 `innerWidth=scrollWidth=320` |
| 浏览器日志 | 本轮设计稿交互未捕获 error／warn |

窄屏尺寸来自浏览器实际 viewport，并通过 DOM 读取确认，没有用缩小截图冒充。
本轮没有检视英文和暗色；生产 PS-16 仍必须完成这些项。
