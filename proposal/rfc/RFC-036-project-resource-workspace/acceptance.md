## 已落实的入口与权限

项目页 `/projects/:projectId/resource-center` 与管理页 `/admin/projects/:projectId/resources` 共用正式资源拓扑、资源清单和申请记录。管理员在同一页面直接分配、撤销、调整配额、设置默认、修改继承与可选范围、开放申请目录及审批。旧 `/compute` 入口重定向到管理资源页，项目原有运行实例页 `/resources` 保留。

| 身份 | 查看 | 申请 | 审批／直接调整 |
|---|---|---|---|
| 项目负责人 | 已有能力、明确开放的申请目录、申请和运行实况 | 资源申请、配额修改及生产访问申请 | 无 |
| 开发者 | 同项目资源与申请进展 | 无；旧 API／生产访问入口同样限制 | 无 |
| 平台管理员 | 项目全景及完整目录 | 直接管理形成可审计变更 | 本页直接管理、批准／改值批准／驳回／重试、撤销生产访问 |

身份以当前角色重新判定；伪造 `isAdmin` 无效。提交、审批和应用前分别检查角色、目录、资源修订及项目状态。隐蔽且未开放申请的目录不向项目泄露；缺少旧 API 目录端口时默认关闭申请和批准。

## 资源类型与生效语义

| 类型 | 本页操作 | 生效证明与影响 |
|---|---|---|
| 服务套餐 | 分配／撤销、继承范围 | 可选范围变更；已有部署保留，新选择仍需发布 |
| 任务容器套餐 | 开发套餐默认 | 后续工作区使用；现有工作区不重建 |
| Agent 算力档位 | 分配／撤销／默认 | 保留继承，后续选择使用；已冻结执行保持 |
| 运行镜像 | 分配／撤销、继承范围 | 授权扩大选择范围；不构建或热换镜像 |
| 对象存储套餐 | 分配／撤销 | 目录与项目授权；不偷偷创建空间 |
| API 操作 | 授予／撤销、目录政策 | 等待当前项目服务的网关放行表确认；平台默认开放不能从项目撤销 |
| 执行并发 | 修改上限 | 原子准入额度更新；已有任务继续运行 |
| 命名空间额度 | CPU 请求、内存请求、Pod、PVC 上限 | 政策、ResourceQuota spec 与 status hard 同步一致后生效 |
| 对象空间 | 容量、单对象大小、传输并发 | 所属模块检查已用／预留／待删除及后端容量，持久回执；项目覆盖不会被套餐重同步抹去 |
| 网关限流 | 四组平均／突发、恢复继承 | 四个实际中间件及对应来源维度一致后生效 |
| 生产数据访问 | 模式／期限申请，管理员撤销 | 绑定原工作区，临时角色实际就绪才生效；不重建工作区，不宣称旧进程已载入连接 |

## 拓扑与计量自查

- 实例、容器和卷使用实际资源身份与 UID；重用同名对象不会合并成同一实例。结束中和归档助手仍计入对应执行占用。
- 工作区使用冻结的规格和镜像版本。旧记录没有冻结规格时显示未知；不从当前目录猜测实际值。单个镜像读取失败保留工作区／发布事实并标记来源不完整。
- 正式与待验证槽连接同一生产数据库和对象空间；开发数据独立。Agent 使用其父任务卷，逐成员保留关系；多个事件订阅入口不会因事件类型相同而被覆盖。
- 生效值、实际用量、预留、申请目标、计量范围和观测时间分别呈现。共享容量不相加，未知不转成零；目录政策与实际占用的指标合并后仍保留实际来源。
- 有界读取：台账 2000、工作区 4×250、镜像目录 20×100、未完成申请 5×100。超过上限明确标记不完整；申请记录可继续分页。
- 不返回环境变量值、DSN、口令、命令或 Secret 内容。配置页只显示声明和元数据。

## 自查发现与修正

1. 关闭受控管理弹窗时，浏览器原生 `close()` 会重新聚焦隐藏表单。调整统一 Dialog 的恢复顺序，保留 StrictMode 与嵌套弹窗回归；关闭／重开仍保留草稿且焦点回到触发按钮。
2. 实例读取夹具曾把没有冻结规格的旧记录当成已有规格。保留未知，再用真实 PG 保存不同于目录的冻结资源验证读取；避免用目录回填实际容量。
3. 旧 API 接线遗漏申请目录端口。用红回归确认缺失配置会绕过显式目录，补上组合接线并将缺配置改为拒绝；目录撤回后不能申请或批准，原记录保持待审。
4. 旧发布记录缺少 compute／objects 时影响关系源读取。对可缺省字段保留兼容，读取两槽真实固定 Manifest，单个图片／版本失败保留其余事实。
5. 到期数据访问曾保留 `active` 展示文字。状态与展示同步为 expired，不画生产访问生效边，不提供撤销过期授权的提交。
6. 拓扑筛选原来只降低无关节点的透明度，完整图仍占据较大高度。先用红回归确认，再将匹配节点及真实归属祖先紧凑排布；只保留已有连线，不虚构到项目的关系。保留成员明细与各自配额，普通图和放大图使用同一结果。包含这项修正的 UI／模型／布局专项 **30 pass／0 fail，203 断言**。
