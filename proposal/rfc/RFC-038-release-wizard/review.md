## 3. 仍需实现后的证据

预览没有真实平台 API、PG、构建 Job 或切流。它展示主要流程与典型历史；没有实现完整历史游标、真实刷新／跨浏览器接续、普通切流幂等、真实日志／应用新标签、维护／回退界面、管理空间或英文页面。

正式实现还需完成计划 T4–T16，并逐项取证：真实数据库阶段事件、精确流程恢复、普通及 fenced 生效、历史只读 Network 轨迹、长列表分页／滚动／焦点、双空间中英、共享外壳 main 滚动和项目删除全范围。本轮没有运行生产门禁、提交／推送或部署，28 项原型检查不抵这些验收项。

## 4. 实施时的依赖

- 新阶段留存和普通切流防重与向导同时落地；仅替换前端弹窗不足以兑现历史进程和刷新恢复。
- 新表迁移与删除 owner 的完整 schema 核对同批提交，否则已有项目永久删除会因未知表阻断。
- 复用镜像、无迁移和直接 API 上线保持原语义；没有人工验证记录时显示未记录，不代用户编造验证成功。
- 同一文件若有并行任务输出，先核对当前候选再编辑，完整保留其内容；整案批准前不修改生产文件。
