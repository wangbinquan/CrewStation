## 4. 真实反例与修正

- 历史返回：原部署在 16 个项目空间场景均把列表滚动重置到 0。三个返回链接有原行上下文时禁用路由默认复位，保留既有恢复逻辑。候选 16 个场景通过；Happy DOM 没有排版，组件测试没有被冒充为真实红例。
- 管理空间窄屏：英文的 slug＋类型在 320px 撑宽导航 30px，初次 14 pass／2 fail。约束共享导航分组的最小／最大宽度后同一 16 场景全部通过，不用隐藏全页溢出掩盖问题。
- 项目开通：原回调在网关准入处试图扩大既有锁范围，被原守卫拒绝。只对 provision 在外部 IO 前取齐公开 owner 准入键；实际 PG 红例转绿后，同一个专用项目恢复开通。
- CI 旧测试：正文 EOF 与持久退出存在合法先后差，改以真实 PG 行锁证明窗口并等原退出；七阶段删除用例按原业务阶段分别验收，全部事务、回执和历史保持。保留原失败 CI，不用重试失败场景或放宽时限掩盖问题。
