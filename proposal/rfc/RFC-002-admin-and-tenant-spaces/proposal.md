# RFC-002 · 管理空间与租户空间分离｜Proposal

- 状态：Draft
- 日期：2026-09-12
- 作者裁定：2026-09-12 四选一确认「管理员空间独立成一级入口」＋「接入容器移出租户列表，归到管理空间」

## 1. 背景

用户 2026-09-12 指出：**现在界面上没有区分管理员和租户空间。**

现状，对着源码：

| 现象 | 位置 |
|---|---|
| 左栏只有一个「平台」分区，下面并排「项目」与「管理员」，**对所有人可见** | `apps/console/src/app/layout/SideNav.tsx:18-27` |
| `/admin` 只在页面内部挡：非管理员进去看到一句「仅管理员」 | `apps/console/src/features/admin/pages/AdminPage.tsx:25` |
| 两个接入容器是平台项目，与业务数字人混在同一张项目列表里 | 本机实测：`demo`、`gitlab-event-producer`、`reference-api-proxy` 同列 |

后端的隔离本身是对的：`listProjects` 对管理员返回全部、对普通成员只返回自己有成员关系的项目（`modules/project/application/queryProjects.ts:30`）。**问题只在界面没有把这层结构表达出来**：

- 普通成员一直看见一个自己永远点不进去的入口，点进去被告知「仅管理员」。这不是权限设计，是没做导航。
- 管理员做的事（用户、套餐、出站白名单、网关、接入容器）和租户做的事（开发、发布、切流）在视觉上是同一层级的并列项，读不出「一个是平台运营，一个是业务自治」。
- 接入容器是管理员维护的平台设施，出现在业务的项目列表里，让租户以为那是自己的项目。

Design §7 定义的角色（管理员 / 项目负责人 / 开发者 / preview 测试者）是有的，界面没有按它分区。

## 2. 目标与非目标

### 目标

1. 工作台顶栏出现**空间切换**：「工作台」与「平台管理」两个空间，各有各的左栏导航。
2. **非管理员完全看不到平台管理入口**——不是禁用，是不存在；直接访问管理路由时给出清楚的拒绝而不是空白。
3. 两个接入容器从租户的项目列表移出，归入平台管理的「接入容器」页。
4. 租户空间里只剩业务自治的事；平台运营的事全部收进管理空间。

### 非目标

- **不改后端权限模型**：`listProjects` 的作用域判定、各路由的 `isAdmin` 校验都已正确，本 RFC 不动。
- **不换域名**：用户已在三选一里排除了「admin.cs.localhost 独立域名」。两个空间同域、同一份构建产物，靠路由前缀与顶栏切换区分。
- **不引入「租户」作为新对象**：本仓的租户单位就是 Project（Design §1.2「`Project` 开发与管理空间」）。本 RFC 只做界面分区，不在 Project 之上加组织层。
- **不做管理员的项目代入视图**：管理员仍在同一个项目页里看所有项目，不做「以某租户身份查看」。

## 3. 用户故事

**普通开发者**：我登进工作台，左栏是「我的项目」，下面是我参与的项目。我看不到任何平台管理的入口，也不会点到一个告诉我「你不行」的页面。

**平台管理员**：我在顶栏把空间从「工作台」切到「平台管理」，整个左栏换成用户与权限、算力档位、服务套餐、任务容器套餐、接入容器、出站白名单、网关。我要看某个业务项目时切回「工作台」。

**接手的运维**：我一眼看得出哪些是平台设施、哪些是业务项目——它们不在同一张列表里。

## 4. 验收标准

1. 顶栏有空间切换控件；非管理员**不渲染**该控件，左栏也没有任何管理入口。
2. 非管理员直接访问 `/admin/*` 时看到明确的拒绝页（不是空白、不是 404），并给出回到工作台的入口。
3. 平台管理空间的左栏至少含：用户与权限、服务套餐、任务容器套餐、出站白名单、网关、接入容器。（算力档位由 RFC-001 加入，本 RFC 只预留位置。）
4. 租户的项目列表**不含** `kind` 为 `APIProxy` 或 `EventProducer` 的项目；这两类出现在平台管理的接入容器页。
5. 管理员在租户空间仍能看到全部业务项目（后端作用域不变）。
6. 切换空间不丢失当前项目上下文：从项目页切到管理空间再切回来，回到原来的项目页。
7. 现有十个页面的功能与路由不因分区而改变。

## 5. 能力影响清单

| 被关闭的能力 | 影响 | 处置 |
|---|---|---|
| 普通成员能看见「管理员」导航项 | 看不见了 | 那本就是个点不进去的入口，移除是修复不是收缩 |
| 项目列表里能看到接入容器 | 租户看不到了；管理员改到管理空间看 | 用户 2026-09-12 明确选定 |

**没有真正的能力收缩**：任何角色能做的事集合不变，只是入口位置变了。后端权限一行未改。
