# RFC-003｜交互附件验证记录

> 日期：2026-09-13 · 对象：[prototype.html](./prototype.html)\
> 本页记录设计演示的检查，不能替代生产代码／真实服务的验收。

## 附件范围

默认以“平台管理员同时担任项目负责人”的示例身份查看。固定显示“设计预览 · 示例数据”。所有交互只更新页面内存，不连接 CrewStation API，不运行模型，不修改集群、成员、授权或配置。

本附件用于评审布局、入口、对象关联、操作顺序、字段错误与反馈。平台设置目录、接入容器内部、数据访问和部分高级能力展示信息结构，完整增删改与真实生命周期以 design／plan 的规格为准。

本轮分隔线的鼠标拖动自动化未取得尺寸变化证据，方向键调整已验证；不能把它记为拖动验收通过。正式实现还需原生 xterm／PTY resize、触摸／鼠标分屏、个人布局持久化，以及真实状态事件去重、断线恢复与全部角色验证。演示状态在页面内存，轮次完成用本地延时模拟，不能作为模型运行证据。

本轮代码与部署均未变化；浏览器检查聚焦设计附件。以下保留两份前稿记录，已被替代的启动方式仅为历史证据。

## 上一稿开发工作区的浏览器验证（提交 a580712）

作者明确要求多原生 CLI、独立实时预览与工作树对生产版本差异后，开发页已替换首稿聊天优先布局。以下记录仅验证新的演示行为：

| 场景 | 实际结果 |
|---|---|
| 一次启动三个 CLI | 未填首条任务，点击一次后有三个独立窗口，先启动中再已连接 |
| 独立输入 | 只给 Agent 1 输入时仅该窗口增加示例输出，其余两个输出不变 |
| 未提交与预览 | 示例修改后未提交文件变为 1，已提交待上线仍为 2；独立预览显示新增状态筛选的效果 |
| 跨视图保留 | Agent 2 的未发送输入跨独立预览／CLI 切换仍保留；窗口名册保持三个 |
| 放大／收起／恢复／结束 | 单窗可放大、收起和恢复；只结束 Agent 3 后其显示已结束，另两窗继续已连接 |
| 比较目标 | 生产 SHA 与当前 HEAD 不同；切到与 HEAD 相同的待验证版本后提交差距为 0，未提交文件仍为 1 |

上一稿的 1–6 窗限制和批量入口已被本轮取消。原生终端在附件中用简化输入和输出展示交互顺序，没有运行 xterm／PTY 或实际模型；正式实现不能沿用模拟输入冒充 CLI。真实浏览器新页签、HMR、终端恢复、版本分叉／历史缺失等仍按专项设计在实现后验收。未执行的示例选项不算测试通过。

## 已修正的演示问题

- 沙箱预览不允许原生表单导航，改为在按钮上派发本地 submit 事件，保证表单验证与反馈真实触发而没有外部提交。
- 新 Agent 改为先填写档位、权限与首条指令；不再直接复制已有 Agent 的对话内容。
- 对话／代码草稿保留，开发与生产配置值分开保存。
- 上线与回退后，标签和 SHA 一起切换；管理员拒绝理由能在租户详情保留。

## 尚未作为验收通过的项目

真实模型输出、Kubernetes 开通与发布、真实服务身份试调、角色授权、成员候选后端、日志保留、并发与断线重放均未在此附件中执行。平台设置全量增删改、接入容器的完整内页、完整明暗主题、屏幕阅读器和全部键盘路径尚需正式实现时验证。

交互原型没有持久化和真实 URL 路由；刷新重置演示数据。目标产品的深链接、浏览器历史、草稿恢复和跨项目缓存约束见 design.md，不以此附件的页面内导航代替实现。
