# RFC-027 · 实施计划与验收

> 状态：Done · 2026-09-27。作者已批准本 RFC 在 CrewStation 完整实现、提交远端和本地部署；CS 实现、分层/集群验收、远端提交及本地部署已完成；真实 aw 接入保留为外部任务。
> 配套：[提案](./proposal.md) · [技术设计](./design.md)

## 1. 阶段与退出条件

| 阶段 | 交付 | 退出条件 |
|---|---|---|
| P0 共同契约 | CrewStation RFC 三件套；aw 接入责任与契约 | 完整稿获批；CS 测试业务客户明确模拟应用必须履行的接口责任，aw 自身 RFC 为后续外部接入项 |
| P1 本地端口与平台基础 | aw 本地执行端口保持行为；CS v3 准入／异步执行／文件／事件 | 平台真实测试客户跑通长命令、幂等、取消及补读；aw 本地行为验证由其任务提供 |
| P2 动态执行与发布控制 | 材料、usage、会话、契约固定、fenced 交接、探针 | BE 平台用例通过，切流／回退／维护失败模式可恢复，v2 回归通过 |
| P3 aw 远程适配 | aw 网关／PG／镜像／执行适配器与工作区助手 | 两仓明确候选版本，真实工作流、人工等待及执行中发布通过 |
| P4 发布收口 | 文档回填、候选验证、部署和精确 SHA CI 证据 | 所有适用验收有终态证据，恢复测试配置，分别报告平台能力与 aw 上线状态 |

P1 的两仓开发可以独立安排，不要求先把 aw 的全部部署改造完成才明确平台 API。独立执行不等于可并发发布共享 Git 索引。本文不授权创建额外工作树、不授权修改 aw 仓库。

## 3. 验收清单

| 编号 | 场景 | 必须观察到的结果 | 验证层 |
|---|---|---|---|
| BE-01 | v3 严格校验、未知字段／保留 env／不支持能力／旧 Runner | 明确拒绝；无 Pod、无新额度、无静默丢配置 | unit、module |
| BE-02 | 同键并发、回执丢失、不同摘要、跨槽重试 | 一个稳定资源／attempt；不同摘要 409；首次 trace 和契约不漂移 | 真实 PG、集群 |
| BE-03 | 父任务准入、Agent 准入 429、故障发生在准入回执之前 | 无容量等待队列；同键可恢复；不多建 Pod、不泄漏或重复退额 | module、集群 |
| BE-04 | 运行至少 90 秒命令并输出首尾标记 | 受理迅速返回；超过 30 秒仍运行；最终退出码和首尾输出完整 | Runner、集群 |
| BE-05 | API／session 重启及 Runner 在 spawn 临界区崩溃 | 原 executionId 不重复启动；可证明的结果恢复；不可证明则 unknown，不自动重做副作用 | Runner、module、集群 |
| BE-06 | 执行期间断线、重复／乱序输出、退出先于尾部输出 | 游标补读不丢不重；finalCursor 在尾部持久化后出现 | unit、module、集群 |
| BE-07 | spool 满、日志超限、持久化失败、历史过期 | 明确错误／截断／gap；410 有恢复入口；不伪称输出完整 | Runner、module |
| BE-08 | 取消与退出竞态、Runner 失联、Pod 删除失败 | 取消中有证据；真实停止后才终态和退额；迟到事件不改新 attempt | module、集群 |
| BE-09 | 文件越界／符号链接交换／保留目录／设备／版本变化／大文件分块 | 拒绝越界，版本变化 409；有界读取；跨服务访问拒绝 | Runner、security、module |
| BE-10 | 活动子任务时 pause，安全点 pause/resume，原卷丢失 | 活动任务 409；清理后退额且卷 UID／内容不变；卷丢失不建空卷 | module、集群 |
| BE-11 | 平台配置＋业务 prompt/skills/MCP/env，冲突与 Secret | 生效摘要匹配；平台项不可覆盖；日志／事件／DTO 无凭据明文 | unit、module、真实档位 |
| BE-12 | 发布材料与运行 cwd 无源码仓库 | systemPromptFile 由发布材料提供；无需假定父任务已检出业务代码 | module、集群 |
| BE-13 | usage 为 none/final/incremental、累计重复事件 | unknown 不算零；增量去重；软预算取消有确认与可能超额说明 | driver、module、测试客户 |
| BE-14 | 并行独立子代理与不透明原生委派 | 每个独立代理有句柄／Pod／额度；原生内部行为不冒充逐 Agent 计额 | 集群、aw |
| BE-15 | 新待命 release、默认档位变化、显式 fresh 重试 | 父任务契约固定；重试保留原修订与镜像，fresh 只新建执行／目录（I34） | 真实 PG、集群 |
| BE-16 | 两次抢同会话、跨任务恢复、旧卷／不兼容修订、真实续跑 | 单会话单写；违规拒绝；支持的档位用原 sessionId 续跑，不支持明确 412 | module、真实档位 |
| BE-17 | 两槽与多副本抢控制、租约过期、旧 epoch 请求 | 一个有效 holder；旧请求拒绝；既有执行继续且无误回收 | 真实 PG、集群 |
| BE-18 | 执行中切流，旧 aw 实例保留 72 小时期间继续发请求 | 新节点只由新 holder 发；旧 aw 写屏障生效；原执行句柄被接管、不重启 | 集群、aw |
| BE-19 | handoff 各阶段崩溃、路由迟到、回执重复、目标激活失败 | 操作可恢复；冻结可诊断；不自动恢复旧 epoch；回退也走新 epoch | module、集群 |
| BE-20 | 非兼容迁移、活动库写者、旧 schema 读不兼容、旧任务契约不支持 | 无停写证明不迁移；不兼容不切流／回退；无伪成功 | module、upgrade、测试客户 |
| BE-21 | 慢启动、依赖未就绪、standby 无租约、v2 模板回归 | startup 保护；readiness 与 liveness 分开；Web ready 不取得执行权；v2 原行为保持 | unit、集群 |
| BE-22 | aw 网关用户登录、过期、WS、机器服务域、平台事件重投 | 身份绑定正确；过期恢复；机器调用可用；持久 inbox 去重 | aw／跨仓端到端 |
| BE-23 | aw clone→并行 iso Agent→文件产物→merge→人工等待→恢复 | 稳定路径、平台额度、事件可见、卷／会话按契约恢复、业务结果正确 | aw／跨仓端到端 |
| BE-24 | aw 空 PG 冷启动、独立迁移 Job、两槽发布／回退、429 背压 | 无本地世代文件依赖；无互相 interrupted；不重复提交；恢复后 UI 历史完整 | aw／跨仓端到端 |

BE 平台分层证据与集群实测对应关系见 [acceptance.md](./acceptance.md)。故障组合由真实进程/PG用例验证，集群证据仅按实际执行范围记录；BE-22～24 和 BE-14/18 中的真实 aw 部分仍未验证。

## 4. 测试落位与发布门禁

- `packages/contracts` 就近单测 v3 schema、字段拒绝和能力；`tests/contracts/` 固定跨进程金样，按授权兼容策略运行 contracts:lock。
- `modules/business-task/domain` 就近测状态、摘要、合成；`modules/business-task/tests` 用真实 PG 验证幂等、冻结、会话互斥和 outbox 恢复。
- `modules/session/tests` 验证业务输出持久化、重放与水位；`runtimes/task/tests` 用真进程验证重启和取消；`tests/security` 验证路径／归属拒绝。
- `modules/release/tests` 验证每个 handoff 阶段和迁移屏障；`tests/upgrade` 验证旧 Runner／v2 与平台回退阻断。
- `apps/console/src/tests` 覆盖阶段、错误、读写边界；真实浏览器核对 320px、键盘、中英文和重连。
- 新迁移只追加本任务文件的 migration lock；本地分层/静态及适用改动行覆盖通过，最终整仓以精确 SHA 的六项 CI 判定；本轮一次完整命令因错误实机登录模式无效，见 acceptance，不冒称本地全量绿。候选内容未变复用验证。
- 集群故障注入使用独立测试项目和专属 Pod，记录恢复动作。发布时精确路径提交，保留并发 WIP；未经授权不提交／推送／部署。
- hosted 证据必须指向包含候选的精确 SHA，并记录 static、unit、module、console、gate、e2e 终态；平台 CI 绿不等于 aw 接入完成。

## 5. 评审与交接记录
