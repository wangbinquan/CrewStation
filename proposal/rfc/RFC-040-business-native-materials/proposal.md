# RFC-040：业务 Agent 原生配置材料

状态：Done，2026-10-18（2026-10-15 用户在当前会话明确“那这个RFC040你接手”，本会话接手实现）。来源：agent-workflow RFC-370 v2 §4、§5 的托管能力等价要求。

## 背景与目标

CS v3 业务材料现已支持附加 systemPrompt、技能、预登记的远程 MCP 和环境变量。AW 的 Agent 定义还包含权限、工具、模型选项、运行时内部子代理、插件以及用户运行时创建的本地／远程 MCP。现有严格 schema 不接收这些内容。只上传提示词会改变已保存工作流的行为。

在仍由平台控制二进制、镜像、网关、模型和凭据的前提下，允许已授权的业务发布提供逐次尝试的原生配置材料。OpenCode 和 Claude Code 各按其真实能力编译；不支持的组合在进程启动前明确拒绝。业务方不获得平台配置编辑权。

## 用户故事

1. AW 用户保存 Agent 权限和温度等选项后，同一工作流在 CS 托管运行保留这些语义。
2. 用户在 AW 创建 MCP 或安装插件后，不必让管理员逐个把它们加入 Manifest 才能使用；业务发布必须预先声明允许相应能力。
3. 同一次尝试因 HTTP 重试或 Runner 重连而恢复时，始终使用首次受理的材料、配置修订和材料摘要。
4. 管理员可以区分业务原生子代理与 CS 调度的 Agent；原生子代理保持不透明内部委派，不伪造独立平台执行、用量或审计。
5. 大体积技能和含二进制文件的插件经对象引用保留全部内容，断线后沿原摘要恢复；不能以 JSON 上限为由裁掉文件。
6. AW 可通过冻结版本的项目 Secret 在任务容器访问私有 Git，服务进程和持久命令参数不承载明文凭据。
7. MCP 测试台能读取本次尝试实际观测到的启动清单。缺失、损坏或协议不支持的观测明确区分，不能把声明已注入当作验证成功。

## 范围与能力影响

新增可选材料版本 `nativeConfig.version = 1` 与发布授权 `businessConfig.nativeConfig`。旧材料、旧发布和没有新能力位的 Runner 保持原路径。默认不授权新能力；请求未经发布允许或运行时不支持的组合得到明确拒绝。

| 能力 | 行为 |
| --- | --- |
| 提示词、技能、已登记 MCP | 保留现有语义，可与新材料组合；同名冲突拒绝 |
| 根 Agent、子代理定义和工具权限 | 保留原生定义，由协议驱动渲染 |
| 变体、temperature、steps/maxSteps | 协议支持则编译；不支持则拒绝，不丢弃 |
| 远程 MCP／本地 stdio MCP | 发布分别授权；本地命令必须在镜像内可用 |
| 插件 | 发布授权后在该次运行私有目录物化；不得覆盖平台观测插件 |
| 模型、模型网关、凭据、二进制、启动 Hook | 继续由平台算力档位控制，业务材料不能覆盖 |
| 大体积技能／插件文件 | JSON 信封保留原限制，文件用不可变对象引用并按套餐预算物化 |
| 私有 Git 的命令环境 | 发布授权后使用冻结版本 Secret，旧字符串环境保持原语义 |
| 启动清单观测 | 按尝试输出有界且脱敏的实际清单；无观测时明确 unavailable，不能根据配置推断成功 |
| 内部子代理 | `opaqueInternalDelegation`，不改变 `platformDelegation` |

不新增页面或新的权限角色，不开放任意平台配置文件写入，不修改已有运行中的 AW 正式服务。

## 验收

两种真实 CLI 分别证明：Agent 指令和权限、技能、远程／本地 MCP、支持的模型选项、内部子代理、支持的插件；每种协议不支持的能力均在启动前以具名错误拒绝。材料重放、对象引用固定与失败恢复、二进制文件摘要、私有 HTTPS／SSH Git、Secret 轮换后同尝试重放、跨尝试恢复、平台配置保留、秘密日志脱敏与原有 v3 用户旅程全部回归。当前机器缺少某种协议凭据时，明确保留该条实机验收未完成，不以桩替代。

## 能力影响补充（2026-10-16 审查修复，需作者逐项确认）

| 变化 | 受影响形态 | 恢复方式 |
| --- | --- | --- |
| 原生能力只认 `nativeProbeVersion: 2` 的 OpenCode 证明 | 已测试但缺该标记的档位暂不宣称 `nativeConfigVersion`／`nativeModelMappingVersion`，原生材料在启动前被拒 | 用新版探针重新测试档位 |
| Claude Code 档位不再宣称原生能力 | Claude 原生材料从未经实机验证（用户裁定只验证 OpenCode），此前的单一正文探针不足以证明 | 后续单独补齐 Claude 探针后再开放 |
| 模型映射要求 Runner `nativeModelMaterialVersion: 1` | 旧任务底座镜像失去内部子代理独立模型 | 升级任务底座镜像并重新测试档位 |
| 原生正文要求 systemPrompt 能力 | systemPrompt 探针失败的档位不能携带非空原生正文 | 空正文仍可用；或修复档位后重测 |
| 对象固定引用按保留期释放 | 父任务关闭或闲置超过 7 天的材料对象不再被固定；用这类材料发起新尝试报 `material_released` | 用原 requestKey 再次受理即复活，材料 ID 与摘要不变 |

新增：对象文件描述独立 4 MiB 预算，10,000 文件的插件树可以受理；内联内容仍为 1 MiB。
