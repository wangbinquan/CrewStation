# 持续 Bot 对话交互原型

运行：`bun proposal/rfc/RFC-041-continuous-bot-session/prototype/preview.ts --serve`，访问 `http://127.0.0.1:51441/`。

这是设计附件，所有发送、完成、中断和恢复均为本地模拟，没有平台 API、模型调用或真实终端。页面复用正式 BotTranscript、BotComposer、BotToolRecord、Button、Badge、Segmented、Dialog 与 ConfirmationDialog；没有修改生产文件。原型草稿和模拟消息仅存在当前页签的 sessionStorage，不能用它证明服务端持久性。

评审路径：

1. 在同一条对话中输入补充需求并发送；使用底部“模拟完成本轮”显示模拟回答。
2. 点击“模拟执行中”，再点聊天输入区“停止本轮”；在原位置继续发送，旧消息保留。
3. 输入未发送草稿，CLI/Bot 来回切换、刷新，检查草稿仍在；CLI 显示自己的独立会话。
4. 打开“历史与设置”及“查看记录”；关闭最上层返回当前对话；嵌套新上下文确认可取消。
5. “模拟上下文缺失”展示真实恢复失败应有的说明；只有确认“以新上下文继续”才开始新上下文，旧历史保留且显示边界。
6. 390px 窄屏在对话/预览间切换，输入框和弹窗均在视口内。

生产实现、实际停止证明、原生上下文卷与冷续接均等待 RFC-041 批准，不把本原型视为正式部署。
