## 2. 验收

| 编号 | 场景与通过条件 | 方法 |
|---|---|---|
| WS-01 | 左栏六项按生命周期顺序；测试者只有版本试用；管理空间接入容器同序、无应用展示 | 用例＋实机两身份 |
| WS-02 | 概览在 1440×900 下主区无纵向滚动（演示项目数据量）；页头有仓库与两槽链接，槽未就绪时不是链接 | 实机量测 |
| WS-03 | 概览三张卡：版本卡与发布页同组件同文案；开发会话卡显示状态、分支、CLI 数、待上线／未提交，未知显示「未检查」 | 用例＋实机 |
| WS-04 | 概览横幅四类各自出现且只在对应状态出现；负责人的待批数据访问横幅直达数据面板 | 用例（四态）＋实机一类 |
| WS-05 | 概览无快捷入口卡、无逐卡刷新按钮、无逐卡「读取于」；页头刷新触发全部查询 | 用例 |
| WS-06 | 开发页只有一条工具行；「＋ CLI」主键一次创建一个 CLI，展开可换档位与权限；阻断原因可见 | 用例＋实机创建一个 CLI |
| WS-07 | 面板：预览／代码／变更／数据／参考／会话打开时终端仍可见并可输入；拖宽在 30%–60%；收起与放大可逆；状态刷新后保留 | 实机 |
| WS-08 | URL 往返：`view=code&file=…` 打开代码面板与文件；`view=split` 等价预览侧面板；`view=diff` 等价变更；无参数进入时地址写回布局中的面板 | 用例＋实机 |
| WS-09 | 旧布局（无 `tool`）迁移正确；保存后旧字段回填；布局冲突提示不丢编辑器草稿 | 契约与纯函数用例＋实机改布局 |
| WS-10 | 数据面板同时有资源表与绑定申请；负责人在此批准；`resources?section=data` 重定向到此 | 用例＋实机 |
| WS-11 | 参考面板可试调已授权操作并记录真实 HTTP 状态与 trace；「全部操作与 Swagger」到开发资源 | 实机（专用验收项目） |
| WS-12 | 会话面板内嵌最近日志与完整日志链接；连接异常时 `ConnectionGuide` 仍在页头下 | 用例＋实机 |
| WS-13 | 没有会话：主区开会话表单，面板只有参考可用 | 用例＋实机 |
| WS-14 | 发布页：上线／回退按钮在待验证卡；`switch=1` 自动检查；时间线合并发布与切流、人名与标签代替 UUID、失败条目有日志入口 | 用例＋实机 |
| WS-15 | 运行与诊断五段分组导航；`tab=health`／`topology` 重定向；状态段两部分；调用链空态说明来源 | 用例＋实机 |
| WS-16 | 开发资源三主题；API 表在前、选中行详情在旁、Swagger 折叠；事件页投递摘要；`section=project` → 项目信息 | 用例＋实机 |
| WS-17 | 项目设置五组；项目信息只读、技术详情折叠可复制 | 用例＋实机 |
| WS-18 | 1440／1280／1024／390／320，中英文、明暗、键盘（面板页签方向键、放大收起可达）：无整页横向溢出、控制台零错误 | e2e 量测＋实机 |

## 3. 完成条件

1. T2 有作者对 D1–D7 的明确裁定记录，三件套按裁定改写。
2. T3–T8 每项带用例；`bun run check` 本机绿，`test:patch --base origin/main` 达标。
3. WS-01…WS-18 每项有可核对证据（用例名或实机截图／量测），写进本目录 `acceptance.md`。
4. 精确 SHA 的 GitHub `gate` 与 `e2e` 成功。
5. RFC 索引、STATE.md、既有 RFC 的修订说明同步；未全部达成时如实分别报告，不标 Done。
