# RFC-029 实施与验收

状态：In Progress · 2026-09-27。作者已明确批准推荐方案；新恢复契约进入实施，尚不能标为当前可用能力。

| 阶段 | 内容 | 退出条件 |
|---|---|---|
| T1 | 与RFC027对齐真实任务只读列表、服务端排序／分页、页面取消内部身份输入 | legacy与v3均可见，失败跨分页仍优先，读取无写副作用 |
| T2 | 恢复评估、持久请求、幂等及操作者审计 | 权限／状态变化／重复键／未知旧执行分支真实PG通过 |
| T3 | 服务认领与fence／租约、恢复操作关联 | 双实例与发布交接拒绝旧epoch，崩溃不重复派发 |
| T4 | 父工作区恢复、子执行retry/resume及原材料校验 | 原PVC／镜像／会话证明，资源停止前不重跑 |
| T5 | v3示例应用接入，工作台详情与确认／进度 | 真正点按钮完成任务恢复，未接入应用原因准确 |
| T6 | 本地部署、独立项目验收、精确提交／CI | 下面所有项有对应真实证据，测试资源清理 |

验收项：

- TR-01：打开即见任务；项目名称、错误原因、失败置顶、过滤／分页正确，包含新旧协议。
- TR-02：选中失败子任务后确认重试，产生一个新attempt；双击／断线／重启仍只有一个。
- TR-03：暂停父任务恢复同卷，镜像／档位默认变化不改变原快照。
- TR-04：失败持久父任务恢复；旧Pod尚存、原卷缺失／UID变化、旧执行unknown分别明确拒绝。
- TR-05：Agent原生会话续跑与fresh明确区分，不兼容不会偷偷换为fresh。
- TR-06：应用离线／未声明能力时显示真实不可用原因；在线后同请求接续。
- TR-07：服务切流、请求认领租约到期、旧进程迟到全部保持fence，不重复业务操作。
- TR-08：非管理员／跨服务认领／篡改目标及材料／撤权后读取或执行均拒绝。
- TR-09：旧票据处理显示真实停止与解除阻塞，不冒充业务已恢复。
- TR-10：320／390／1440px、中英文、键盘与确认焦点、真实错误／空／等待／成功状态。
- TR-11：完整门禁、精确SHA CI与部署版本一致；验收仅操作本轮新建任务及资源，原有UID不变。
