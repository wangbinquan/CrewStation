## 验证与共享工作树

生产实现落地时使用现有 `adminAuthentication.test.tsx` 与角色回归，补新增交互测试；不要为适配布局去删除业务断言。依赖真实权限变更的实机操作，应使用明确获授权的测试对象；本轮设计稿仅在内存中演示。

提交前运行 `bun run check`、console build；核对无等价全量门禁正在运行，不因无关 HEAD 移动启动重复门禁。新增生产文件必须被测试加载。共同 index、STATE.md、RFC 索引按现行并发规则处理，保留他人的全部内容。

设计阶段仅作只读观察，未改变平台配置。批准后的正式实现与真实 API 验收记录见 [acceptance.md](./acceptance.md)；设计附件不计入生产实现的通过证据。

## 设计附件核对（2026-09-20）

- HTML fragment 约 54KB，JavaScript 语法检查通过；不含网络接口调用，示例修改不写入平台。
- 搜索「陈」只展示陈予安；改为不存在的姓名显示独立空态；清除后按开发者筛选正确更新列表。
- 示例用户陈予安从开发者选为用户，先显示旧 → 新角色，再确认保存，列表与反馈更新。
- 示例接入方改显示名为「星河公司账号」，切换连接设置后回到基本信息保留草稿；返回触发放弃确认，继续编辑后保存，列表回显新名字，空密钥未被替换。
- 连接测试展开标为「模拟」的逐端点来源与地址；键盘 ArrowRight 将登录方式切换为身份字段且焦点随之切换。
- 项目覆盖选择知识助手，取消显示名与邮箱后，显示固定 ID／令牌仍传递的说明，空集合可以保存，列表显示「不传递可选身份字段」。
- 浏览器默认窗口 1280px（原型实际 1248px）已观察两页深色效果。内置浏览器 viewport 控制未改变实际视口，改用仅监听 127.0.0.1 的预览夹具设置 iframe 宽度；量测原型 1024px 时角色编辑为 484px＋290px 两栏，scrollWidth=1024；390px 用户页、320px 登录方式／接入基本信息／用户页／身份字段均 scrollWidth 等于指定宽度，登录页控件没有超出边缘。
- 浅色 1024／390／320 与深色 1248／320 做了抽查。这不是全尺寸×全主题×双语的完整组合验收；英文、真实接口、提交失败／冲突等正式实现项仍列在 UA 清单。

附件是用于批准视觉和主交互的模拟稿，后端错误、完整 Schema 验证及新增接入方的真实登录不由它证明。以上为 2026-09-20 批准前的设计记录；当时正式实现尚未开始，不代表下方正式实现阶段的当前状态。
