## 实现结果

- 用户目录以姓名、邮箱和文字角色为主，搜索与筛选可组合。按需打开单个角色编辑器；保留 `expectedRole`、409 重读、再次确认、`users/me` 刷新和权限守卫。
- 认证拆为登录方式／身份字段两个可直达标签。接入配置按基本信息、连接设置、账号规则、字段映射分组，原有配置完整往返；错误按组计数并定位首错，草稿离开需确认。
- 连接诊断按接入方独立记录请求与配置版本，明确区分失败、未测和过期；端点展示完整地址、来源和复制操作。
- 身份字段同时展示名称、协议键、来源与状态。项目按名称和完整 ID 选择；未知字段与不可读项目保留，空集合仍是有效的项目自定义规则。
- 仅修改 console 交互与样式，不改 HTTP 契约、数据库迁移或权限规则；复用现有主题、布局、表单和确认控件，新增通用原生选择行与复制按钮。
