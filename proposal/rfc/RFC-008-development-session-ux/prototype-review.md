# RFC-008｜设计附件核对

> 2026-09-20 设计审核阶段记录；仅设计稿，不能计入生产 DS 验收。批准后的实现与实机证据见 [acceptance.md](./acceptance.md)。

## 已核对

- 故障入口直达“会话与环境”，将页面连接和容器连接分行显示。
- 模拟检查恢复条件 → 选择套餐 → 确认保留工作树 → 回到可创建 CLI 的状态；模拟过程没有真实 API 调用。
- 创建一个模拟 CLI 后，输入内容可保留；切换数据访问／代码／CLI 后，三处输入均仍存在。
- 数据访问与会话信息各占内容区，不再覆盖终端或拉伸右上角工具栏。
- 1280×720 实测四个窗口均为 536×215px；第一行顶端约 209px，第二行底端约 647px，四个输入区均在视口内。
- 390px 同源 iframe 实测六个视图的 documentElement.scrollWidth 都为 390px；四窗自动变为单列，页面不横向溢出。
- `bun build …/prototype.js` 与 `bun run arch:check` 通过；`git diff --check` 通过。

## 附件范围

可操作：功能页签、故障入口、模拟保卷恢复、逐个创建 CLI、创建工作区、收起／找回窗口、排布与并排预览、表单与代码草稿。
日志、发布、历史对话、释放按钮显示去向说明，不调用后台。
底部“演示状态”是评审工具，正式产品不包含它；所有终端与版本数字均为演示。
本设计审核记录不证明真实 PTY、保卷重建、模型执行、数据库申请、生产读写或发布已验收；实际范围以后续 acceptance.md 为准。
