# RFC-017｜项目资源配置管控

状态：Done · 2026-09-21。作者在确认“项目资源配置＋共享规格模板”的两层方案后回复“改”，授权实施。

## 目标

项目管理提供项目列表和资源规格模板两个入口；服务／任务容器套餐作为全平台共享模板放在后者。具体项目的“算力授权”扩展为“资源配置”，集中服务规格范围、Agent 与开发容器、并发配额和占用。旧地址保留跳转。

## 配置规则与影响

| 配置 | 规则与生效时点 |
|---|---|
| 服务规格范围 | 默认继承全部目录，兼容已有项目；可显式分配清单。Manifest 继续选择服务规格，数据库迁移前和部署前都检查范围；空清单阻止后续部署。运行实例与已有版本切流不受影响。 |
| 开发容器与 Agent | 沿用 RFC-012，开发新建／恢复采用分配套餐；Agent 使用档位绑定的规格。 |
| 并发配额 | 1–100，显示真实占用。新上限只影响后续受理，降低不会终止既有任务。 |
| 共享模板 | 明确标记全平台共享。服务规格下次发布采用；任务规格下次创建采用。 |
| 权限与草稿 | 管理员配置、成员读取；服务政策用 revision CAS，配额按旧值比较保存。各卡片独立保存和重读，失败保留草稿。 |

验收：PR-01 导航与旧地址；PR-02 统一资源入口；PR-03 服务继承／限制／空清单；PR-04 项目隔离与发布拒绝；PR-05 角色与未知资源；PR-06 CAS；PR-07 配额边界／占用；PR-08 草稿与错误；PR-09 中英文与窄屏；PR-10 门禁与发布证据。
