# RFC-037 弹窗交互稿

复用工作台的 FormDialog／Dialog／ConfirmDialog、FormField、Button、Badge、DataTable 与主题令牌。展示管理员代建、开发者自建、新建弹窗与删除二次确认，不连接平台 API，不创建或删除真实项目。

运行：

```sh
bun proposal/rfc/RFC-037-project-creation-and-deletion/prototype/preview.ts
```

打开 [本机交互稿](http://127.0.0.1:5217)。顶部可切换两种身份与深浅主题。点击“新建项目”，填写名称与域名标识即可预览正式／待验证域名，选择模板查看用途，展开资源设置；取消／Esc 保留草稿，“清空”不关闭弹窗。管理员列表行的“删除项目”可查看盘点和内层输入 delete 的确认。

示例域名 `apps.example.cn` 是明确的演示数据；正式实现必须调用后端实际安装配置，不能照抄此后缀。模板说明依据仓内两个真实模板的用途，模板 ID 在此仅是交互选择键，不能作为正式创建输入。资源数和身份是演示数据，不能作为真实清理或权限证据。
