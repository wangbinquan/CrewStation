- 在现有主 checkout 的 main 上只读核实字段、域名、模板初始化、归档、资源回收与模块边界。

- 交付前再次 fetch，main／origin 同为 `b643e53196e2eea0d61a6160df7f543263c5a561`，0／0，暂存区为空；相对调研基线只前进了 RFC-034 的三个文档，不改变本轮所核实的创建／资源源码。本会话未执行 Git 历史或发布操作。
- 作者补充要求已覆盖：保留两字段，说明域名与模板用途，渲染实际最终域名；界面美化并改为弹窗，让使用者不依赖指导书；弃用自动生成／隐藏的建议。
