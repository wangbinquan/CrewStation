## 创建与实际入口

- 普通创建、管理员代建及接入列表通过既有 FormDialog；旧创建地址回到列表并打开弹窗。取消和 Esc 不触发创建，列表筛选、滚动及焦点有回归保护。
- 标识的三个地址来自服务器 HostNaming；非法输入、来源错误、迟到或不匹配回执清除预览，不猜测安装后缀。模板默认选中仍可更换，模板内容与必配项按实际目录显示。
- 成功回执核对原输入；未知结果只能继续核对完整分页目录，避免重复创建。身份刷新失败会隐藏弹窗，恢复后草稿保留而不自动提交。

## 生命周期和持久屏障

- project 受理在同一事务内创建操作、写 outbox 并进入 deleting；相同请求键重放原操作，根记录消失后也不生成另一操作。
- 当前 project/config/identity/resources 的屏障为数据库事实，校验原操作、世代、参与者及确认摘要。内容清理保留最小身份/摘要墓碑；迟到回调不能按旧键复活材料。
- 准入共享锁与排他封闭使用独立小池，普通业务事务独立提交，真实数据库对象仅包装 transaction，普通查询监测及 `$client` 保留原行为。SQL 对 backend、数据库、项目 key 和实际 shared 锁逐项核验。单连接与排他等待后的嵌套 UOW 已验证；外部异常不会回滚先前已提交的物理绑定。

- 原 Pod 带本次操作保护，需原节点活跃及所有容器实际终止，先持久化最小停止摘要，再以 UID/RV 移除本平台保护。不存在原 Pod 且没有证明不视为停止。

- Namespace 盘点全 discovery 与全部分页，未知或跨项目对象阻断，正常 finalizer 未结束返回等待，不强制移除。
