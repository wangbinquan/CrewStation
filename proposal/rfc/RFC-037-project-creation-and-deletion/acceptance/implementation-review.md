# 创建与删除底座候选复核

本文件为本会话的限定源码复核，不能替代独立实现复核、完整门禁或实机验收。永久删除入口仍由全参与者装配门关闭。

## 创建与实际入口

- 普通创建、管理员代建及接入列表通过既有 FormDialog；旧创建地址回到列表并打开弹窗。取消和 Esc 不触发创建，列表筛选、滚动及焦点有回归保护。
- 标识的三个地址来自服务器 HostNaming；非法输入、来源错误、迟到或不匹配回执清除预览，不猜测安装后缀。模板默认选中仍可更换，模板内容与必配项按实际目录显示。
- 成功回执核对原输入；未知结果只能继续核对完整分页目录，避免重复创建。身份刷新失败会隐藏弹窗，恢复后草稿保留而不自动提交。

## 生命周期和持久屏障

- project 受理在同一事务内创建操作、写 outbox 并进入 deleting；相同请求键重放原操作，根记录消失后也不生成另一操作。
- 当前 project/config/identity/resources 的屏障为数据库事实，校验原操作、世代、参与者及确认摘要。内容清理保留最小身份/摘要墓碑；迟到回调不能按旧键复活材料。
- 准入共享锁与排他封闭使用独立小池，普通业务事务独立提交，真实数据库对象仅包装 transaction，普通查询监测及 `$client` 保留原行为。SQL 对 backend、数据库、项目 key 和实际 shared 锁逐项核验。单连接与排他等待后的嵌套 UOW 已验证；外部异常不会回滚先前已提交的物理绑定。

## 物理证明与边界

- 原 Pod 带本次操作保护，需原节点活跃及所有容器实际终止，先持久化最小停止摘要，再以 UID/RV 移除本平台保护。不存在原 Pod 且没有证明不视为停止。
- PVC、PV 和供应器位置先固定；未绑定卷只能接受同一原 PVC 的首次实际绑定。CSI 等待原 Delete 供应器回收；local-path 还需原节点认证探针确认目录不存在。同名替换和不可读来源阻断。
- Namespace 盘点全 discovery 与全部分页，未知或跨项目对象阻断，正常 finalizer 未结束返回等待，不强制移除。
- 这些来源已由公开工厂和真实 PG/假 API 用例检查；仍缺实际数字排空、所有旧执行来源、SCM/数据库/对象/镜像回收及剩余 owner。platform 尚未注入完整 deletion 配置，客户端存在接口声明不表示产品可永久删除。

- 首次完整检查的归档命名空间超时由准入锁占满普通池造成，已由原路由回归与单连接反例修正。
- 共享资源中心的继承范围入口按统一弹窗测试，旧配额/限流编辑器明确为兼容部件；正式配额/申请旅程继续由资源中心路由用例覆盖。API 申请夹具采用 owner 和实际可申请目录。
- 短镜像并发准入允许至多一秒等待以恢复幂等重放；长期占锁返回冲突并释放事务，既有 CAS、权限和容量规则保留。
- HTTP 登记使用完整静态路径，继续接受原接口面锁检查。资源中心页签复用统一 Button 的尺寸。

## 后续 API／资源申请／重新确认候选自查

- API 登记、授权、申请、分配回执的所有历史都进入完整内容摘要；未知表和无原代理／ID 的孤儿操作阻断。调用方未发布 API 时也经真实服务目录固定所属项目，再写授权／回执，关闭原迟到 SQL 和旧 ID 搬移。
- 最小屏障记录真假 scope 验证，不能把失败后第二次 seal 当作成功。资源申请在途工作独立持久化；真实连接断开并不清空事实，后台仍等待原回调退出或原 operationId 的领域提交证明。SQL 直接完成／删除在途事实被拒。
- 持久层在 outer transaction 已因断线拒绝时，迟到外部回调仍完成自己的 finally，但驱动内部不会再尝试 COMMIT／ROLLBACK 死连接。普通 UOW 独立提交、后续工作无失效 shared 身份；真实 shared／exclusive 断线用例通过。
- 重新确认仅在尚未进入 stop 的受阻操作中推进，同一操作、原根记录和已完成证明均保留；当前摘要与最小确认历史原子写入 outbox，失败回滚。请求键在首次与各次更新之间由相同数据库锁串行核验，旧／新请求均可跨删根重放。
- 内容摘要与稳定物理来源分别标记。已封闭范围或外部引用变化不能隐去；原 UID/OID/远端 ID 消失、替换或被改成 metadata 时不能接受新计划。完整新来源不可读、过期、材料又变化均阻断。
