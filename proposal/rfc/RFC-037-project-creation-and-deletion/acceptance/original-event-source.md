新 events/0007 只替换本 schema 的归属函数和守卫，原 0006 字节保持。归属未知的历史内容拒绝新增，原 ID 不可重写，其他项目数据保持。gateway/0010 无损回填旧服务、开发来源的 UID，未知旧业务 UID 从实际 Pod 重新观测；同名新 Pod 的索引不会被原 UID 的删除事件清掉。

identity 固定事件受众验签，并通过 platform 的原生适配器核对实际 Pod UID/IP/namespace、原 release/task ID、正式项目/服务归属与当前准入。HTTP 在读取正文之前固定原调用者，真正写入仍核对生产方原 UUID 和双端事务准入。旧令牌、替换 Pod、替换归属及删除中的原项目均不能借同名新项目授权。正常 terminating Pod 不以 Ready 或短令牌寿命被误判为已退出。

自查核对了分层、失败时拒绝、旧迁移字节、v1/v2 合法路径、平台能力兼容和滚动顺序。原生适配器只读 K8s 和各 owner 的公开 API；HTTP 没有跨层引用端口，application 没有引用其他模块。控制器先升级并刷新 UID 索引，再升级 auth/events。来源校验不会替代消费者停止或镜像/卷物理回收证明。
