# 原任务目录容量与旧数字键接线

本批是原 Session 数字副本的接线候选，尚未提交或部署。创建弹窗的既有交付保持；永久删除入口和普通 native usage producer 继续关闭。

## 本次行为

- 封写目录用一个 JSONB 参数读取全部原任务键，避免 PostgreSQL 单句 65,534 参数上限。不会按上限截断原目录，仍校验完整归属并按规范任务 ID 分页。
- 私有内部 HTTP 仅接受规范任务 ID。适配器从当前持久封写范围与不可变 `session.task_origins` 查找原存储键；旧数字字符串只作为 SQL 存储键，不会强转为 TaskId。
- 单一原数字存储键可提供业务原执行、原事件、原数值页、消费确认和终态证明，也可提供开发登记、数字页、确认及排空。两类消费均使用原存储键的实际私有回调与 finally，原页面在 ACK 前重放。
- 开发 JSON 中经归属核实的 runtime/execution 字段仅在返回边界映射为规范 ID。数据库内原登记和旧终态证明保持，其他任务字段或来源身份不一致时拒绝改绑。
- 同一任务有多个实际数字存储键、缺少原来源登记、孤立数值事件或水位矛盾时明确阻断。直接访问数字 HTTP 也执行完整来源检查，不能绕过任务目录并把孤立事件报成 EOF。
- 新增私有适配器拒绝新增执行、登记、事件、Runner 水位确认和普通轮询；停止后的数字副本仍不允许读写。停止和存储回收证明继续由原运行来源负责。
