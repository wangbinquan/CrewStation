# RFC-043：业务任务运行镜像升级（保留工作卷）

> 状态：In Progress · 2026-10-19 · 作者已裁定立项，并批准按设计实现（「Approve as designed」）。
> 来源：AW RFC-370 v4 托管实机验收。持久工作卷的父任务终身保持创建时的任务镜像，服务后续发布新增的卷内命令在这些父任务上永远不可用。

## 问题与目标

业务任务在准入时固定运行镜像快照：`modules/business-task/application/taskRuntimeImage.ts:27-35` 写入 `intent.task.runtimeImage` 并计入 `effectiveDigest`，`modules/task-runtime/application/createEnvironment.ts:79,94` 写入 `render.image` / `render.runtimeImage`。此后各条路径都原样复制它：
- 暂停后恢复：`modules/task-runtime/application/business/workspace.ts:55-74`；
- 重建工作区：`.../business/rebuild.ts:14-58`；
- 重新执行：`.../business/restart.ts:38-40`。

持久卷的父任务因此终身停在创建时的镜像。AW 的任务镜像随发布演进、会新增卷内命令，于是：
- 开发工作区 `development:shared` 与长期任务卷在服务升级后永远用不上新命令；
- 2026-10-19 本机实测：开发自动化的 `repository-facts-scan` 报未知操作，旧任务的「变更」页返回 410。

目标：服务可以把自己的一个**已暂停**持久业务任务，改钉到**同一运行镜像**的另一个版本。该版本须已对当前平台合同通过任务用途验证，缺省取当前正式发布声明的版本。任务身份、工作卷与卷内文件不变，下一次恢复以新镜像启动。

## 用户旅程

1. 服务发布新版本，Manifest `spec.tasks.runtimeImageVersionId` 指向新的已验证版本（已有能力）。
2. 服务在某个持久任务空闲时把它暂停（已有能力），随后请求「升级运行镜像」。可以省略目标版本，由平台取当前正式发布声明的版本。
3. 平台校验并原子改钉，返回一个操作。任务保持暂停，任务视图的 `runtimeImage` 显示新版本。
4. 服务恢复任务（已有能力）：新容器以新镜像挂载原工作卷启动，运行镜像的初始化步骤照常执行。
5. 项目成员在任务详情看到当前镜像版本，事件日志记录这次升级。

## 权限与能力影响

- **谁能请求**：只有持有该服务执行权的正式发布（fence）可以请求，身份证明与暂停 / 恢复相同。不新增角色，也不开放给平台用户。
- **目标版本**：只接受同一运行镜像（`imageId`）、状态可用、对当前平台合同已通过任务用途验证的版本，并且必须是正式发布的缺省版本或其允许列表中的版本（与任务创建同一规则）。
- **任务状态**：只升级暂停的持久业务任务，即无 Pod、存储停止已证明、无活动子执行。运行中、创建中、重建中或已关闭的任务一律拒绝。
- **新增能力，不收缩既有能力**：
  - 未升级的任务行为不变。
  - 镜像引用按版本保留：升级后确认新版本引用、释放旧版本引用，旧版本不再被引用后即可照常退役。
- **初始化须幂等**：新镜像的初始化步骤在保留的 `/work` 上运行，与恢复时相同。

## 验收

- RIU-01：只接受同一运行镜像、状态可用、对当前合同已通过任务用途验证、且属于正式发布选择集的版本；其它一律拒绝，并给出可分辨的原因码。
- RIU-02：只升级暂停的持久业务任务；运行、创建、重建、关闭或仍有活动子执行时拒绝。调用方必须持有当前执行权。
- RIU-03：升级后任务身份、工作卷（PVC UID）与文件不变，代次加一。恢复后新容器使用新镜像并完成初始化，任务视图显示新版本。
- RIU-04：同一 `requestKey` 重放返回同一操作。目标与当前版本相同时视为已完成。升级与恢复、关闭等生命周期操作互斥。
- RIU-05：平台重启或回执丢失后，操作可以冷恢复；失败的升级不改变原来钉住的镜像。
- RIU-06：
  - 镜像引用随升级迁移：新版本引用确认、旧版本引用释放；关闭任务时释放当前版本的引用。
  - 恢复动作的评估以当前镜像为准，不再误报 `original_image_incompatible`。
- RIU-07：在真实 PostgreSQL 与本机集群上，AW 正式实例的开发工作区 `development:shared` 从旧镜像升级后，开发自动化的新卷内命令可用。契约锁与迁移锁同步更新。
