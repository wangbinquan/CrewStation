## 2. 方案要点（对应 2026-09-22 的十四问，作者回复「按你推进的来做」）

- **界面宽度用满（作者看过第一版后的裁定）。** 形态图按容器宽度铺满：泳道数与间距不变，节点随容器撑宽（`fitMetrics`，1:1 不缩放，容器比最窄排布还窄时才等比缩小）；
  项目层列数随宽度取 2–8 列；概览缩略改为一行横带汇总卡；附件内容区不设最大宽度。生产外壳现有 `--cs-content-max-width: 1200px`，只有开发页去掉，实施时至少这三处页面去掉上限，是否全局去掉见 §5。
- **Archify 只做对照。** 它是 Agent 技能加 Node CLI（tt-a1i/archify，MIT，v2.17.0-dev.1），把 JSON IR 渲染成自包含 HTML，没有运行时库、没有喂活数据的接口。
  作者说明「说 archify 是指它渲染的图好看」，认可借鉴其视觉写工作台自己的组件。`prototype/archify/crewstation-platform.architecture.json` 是我按平台架构写的 IR，
  经 `archify validate` 零错误后 `deliver` 出 `crewstation-platform.html`（约 830KB，含其 Viewer；已生成在本机，不进入生产构建，也不建议入库）。
- **借鉴了什么。** 固定的语义色词汇（颜色只表达含义：网关／身份／服务槽／开发会话／业务任务／构建与迁移／数据与存储／平台组件／外部系统）、
  语义色描边加半透明填充的圆角节点、左上角类型线框小图标、虚线边界框带等宽小标题、正交圆角连线与遮罩小字标签、带计数的图例、点选／悬停聚焦压暗无关节点、明暗两套。
  **没有照搬的**：全等宽字体（标题沿用工作台 sans）、品牌图标（含 CC-BY-SA／NC 条目）、Google Fonts 拉取、775KB 的 Viewer。
- **状态不靠颜色单独表达。** 状态点＋状态短语在第二行右侧；等待中虚线边框、失败红边＋警示三角、外部系统点线边框、已完成淡填充。Running 不等于 Ready，状态短语原样保留（如 `ContainerCreating`、`Insufficient cpu`）。
- **连线分两种证据。** 实线是观测到的关系（路由到、管理、从属、挂载、连接）；虚线是静态架构标注（调用、回连、推送、控制），图例明写「不是实测」。系统层只有静态标注，节点状态来自盘点。
- **确定性分层排布。** 横向泳道「入口 → 工作负载 → Pod → 数据与存储」，纵向横带「线上槽／待命槽／开发会话／业务任务／构建与迁移」；位置只由数据顺序或显式行号决定，换快照不重排；不引入 dagre／elk，零新依赖。
- **项目层聚合。** 异常项目置顶；正常项目超过 60 个时只显示前 12 个，末尾一张「还有 N 个」卡片点开展开。
- **窄屏降级。** ≤640px 不画 SVG，改为按横带分组的列表，语义与状态提示一致。
- **详情只读。** 右侧详情复用 Card／Tabs／DefinitionList／Badge：概览、关联（可点跳）、容器、事件；管理动作仍在集群管理的资源详情里，这里不做。
- **RFC-010 口径保留。** 部分来源失败时计数显示占位而不是 0，观测行明写失败来源；快照时间与「每 15 秒换一份、位置按 UID 固定」写在图上方。

## 5. 留给作者的几个取舍

1. **详情面板放右侧还是下方。** 右侧（沿用 RFC-010）会把全图压窄到出横向滚动；放下方则要来回滚。附件按右侧做，宽度 ≥1100px 生效。
2. **系统层的静态调用线要不要默认显示。** 附件默认显示并在图例标明「不是实测」；也可以默认只画节点，勾选后再画。
3. **项目成员看 Pod 级信息的边界。** 附件按 Q6 推荐给出镜像、节点名、容器状态，不含环境变量；实现时需要新的项目范围只读接口（同一份快照按项目过滤）。
4. **语义色是否进 `tokens.css`。** 附件把九组 `--topo-*` 放在 `prototype.css`；实现时建议进 tokens.css 作为正式令牌，其余样式进组件的 CSS module。
5. **Archify 对照图的去留。** 若你觉得静态架构图有价值，可作为集群页「系统架构」的静态附件定期重生成；否则只作本次对照，不入库。
6. **1200px 内容上限是否全局去掉。** 你已裁定形态页面用满宽度；生产外壳的 `--cs-content-max-width` 目前对除开发页外的所有页面生效。只给运行与诊断、集群管理、项目概览去掉，还是所有页面一起去掉？**作者答复（2026-09-22）：全部页面一起去掉。** 已直接改生产：`AppShell.module.css` 的 `.content` 去掉 `max-width`，`tokens.css` 删除 `--cs-content-max-width`，`projectNavigation.test.tsx` 加回归，RFC-003 §6 回填。
