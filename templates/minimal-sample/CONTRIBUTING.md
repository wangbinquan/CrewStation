# 参与开发

本项目是 CrewStation 上的一个数字人。平台能力——网关注入的身份请求头、配置与密钥、内部 API 目录与授权、事件订阅、Agent 业务任务——的权威说明不在本仓库里，而由平台实时提供，内容随本服务当前的授权、绑定、订阅、配额与套餐变化。请以下面两个入口为准，本文不复述其内容：

- **能力说明 MCP**：开发会话内的 Agent 可直接读取它的只读 resource（平台能力目录、本服务现状、约定说明与接口示例）。给 Agent 的第一条指令可以是“先阅读能力说明 MCP，再……”。
- **工作台 → 本项目 → 能力页**：同一份内容的网页版，附本服务已获授权接口的 Swagger、数据绑定、订阅、配额、套餐与环境地址。

本仓库自身的约定：

- `crewstation.yaml` 是与平台的唯一契约：改端口、配置项、开放与订阅、Agent 档案、迁移策略都在这里改，发布时由平台校验。
- 不写登录代码，不读 cookie，不解析令牌；身份只来自网关请求头（`src/platform/identity.ts`）。
- `bun test` 必须通过；每个 HTTP 路径至少一条测试。
- 发布只经平台（工作台发布按钮／`crewstation` CLI／操作 MCP）；手工打的标签不会发布。
