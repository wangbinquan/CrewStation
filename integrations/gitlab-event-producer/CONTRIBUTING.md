# 参与开发

本项目是 CrewStation 上的一个接入容器（`kind: EventProducer`）。平台能力——网关的服务域识别、配置与密钥、事件中心的去重与投递、内部 API 目录与授权——的权威说明不在本仓库里，而由平台实时提供，内容随本服务当前的授权、绑定、订阅、配额与套餐变化。请以下面两个入口为准，本文不复述其内容：

- **能力说明 MCP**：开发会话内的 Agent 可直接读取它的只读 resource（平台能力目录、本服务现状、约定说明与接口示例）。给 Agent 的第一条指令可以是“先阅读能力说明 MCP，再……”。
- **工作台 → 本项目 → 能力页**：同一份内容的网页版，附本服务已登记的事件类型、投递记录、配额、套餐、环境地址、出站白名单与被阻的出站请求。

本仓库自身的约定：

- `crewstation.yaml` 是与平台的唯一契约：改端口、配置项、`producer` 名、`ingress.path`、`produces` 都在这里改，发布时由平台校验。
- **`spec.produces` 与 `src/gitlab/eventType.ts` 的白名单必须一致**：`cs-events` 对未登记的事件类型返回 404。`src/gitlab/eventType.test.ts` 会比对两者，加类型时两处一起改。
- 不写登录代码，不读 cookie，不解析令牌；webhook 的真伪只由 `X-Gitlab-Token` 判定，投给 `cs-events` 的请求不带任何凭据。
- 密钥不进日志、不进响应体、不进错误信息。
- `bun test` 必须通过；每个 HTTP 路径至少一条测试，映射与去重键这类纯函数逐分支覆盖。
- 发布只经平台（工作台发布按钮／`crewstation` CLI／操作 MCP）；手工打的标签不会发布。
